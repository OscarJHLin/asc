Manual
Quick Start
1
Start Master node on your server:
asc master --host 0.0.0.0 --port 52414 --api-port 8080 --non-interactive --skip-benchmark
2
Start Worker node and connect to Master:
asc worker --master-host <MASTER_IP> --master-port 52414 --non-interactive --skip-benchmark
3
Open WebUI at http://<MASTER_IP>:8080 and enter API Key to manage the cluster.
Autostart on Boot

Run the following commands on each node's machine. Replace <MASTER_IP> with the actual Master IP address.

Linux (systemd)

Master node autostart:

sudo tee /etc/systemd/system/asc-master.service <<'EOF' [Unit] Description=ASC Master Node After=network.target [Service] Type=simple User=$USER WorkingDirectory=$PWD ExecStart=$(which python) -m asc.cli.main master --host 0.0.0.0 --port 52414 --api-port 8080 --non-interactive --skip-benchmark Restart=on-failure RestartSec=5 [Install] WantedBy=multi-user.target EOF
sudo systemctl daemon-reload && sudo systemctl enable asc-master.service

Worker node autostart:

sudo tee /etc/systemd/system/asc-worker.service <<'EOF' [Unit] Description=ASC Worker Node After=network.target [Service] Type=simple User=$USER WorkingDirectory=$PWD ExecStart=$(which python) -m asc.cli.main worker --master-host <MASTER_IP> --master-port 52414 --non-interactive --skip-benchmark Restart=on-failure RestartSec=5 [Install] WantedBy=multi-user.target EOF
sudo systemctl daemon-reload && sudo systemctl enable asc-worker.service

Disable autostart:

sudo systemctl disable asc-master.service
sudo systemctl disable asc-worker.service
Windows (Task Scheduler)

Master node autostart (run in CMD as Administrator):

schtasks /create /tn "ASC_Master" /tr "cmd /c cd /d %CD% && python -m asc.cli.main master --host 0.0.0.0 --port 52414 --api-port 8080 --non-interactive --skip-benchmark" /sc onlogon /rl highest /f

Worker node autostart:

schtasks /create /tn "ASC_Worker" /tr "cmd /c cd /d %CD% && python -m asc.cli.main worker --master-host <MASTER_IP> --master-port 52414 --non-interactive --skip-benchmark" /sc onlogon /rl highest /f

Disable autostart:

schtasks /delete /tn "ASC_Master" /f
schtasks /delete /tn "ASC_Worker" /f
macOS (launchd)

Master node autostart:

cat <<'EOF' > ~/Library/LaunchAgents/com.asc.master.plist <?xml version="1.0" encoding="UTF-8"?> <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd"> <plist version="1.0"> <dict> <key>Label</key><string>com.asc.master</string> <key>ProgramArguments</key><array> <string>$(which python)</string><string>-m</string><string>asc.cli.main</string> <string>master</string><string>--host</string><string>0.0.0.0</string> <string>--port</string><string>52414</string><string>--api-port</string><string>8080</string> <string>--non-interactive</string><string>--skip-benchmark</string> </array> <key>RunAtLoad</key><true/> <key>KeepAlive</key><true/> </dict> </plist> EOF
launchctl load ~/Library/LaunchAgents/com.asc.master.plist

Worker node autostart:

cat <<'EOF' > ~/Library/LaunchAgents/com.asc.worker.plist <?xml version="1.0" encoding="UTF-8"?> <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd"> <plist version="1.0"> <dict> <key>Label</key><string>com.asc.worker</string> <key>ProgramArguments</key><array> <string>$(which python)</string><string>-m</string><string>asc.cli.main</string> <string>worker</string><string>--master-host</string><string><MASTER_IP></string> <string>--master-port</string><string>52414</string> <string>--non-interactive</string><string>--skip-benchmark</string> </array> <key>RunAtLoad</key><true/> <key>KeepAlive</key><true/> </dict> </plist> EOF
launchctl load ~/Library/LaunchAgents/com.asc.worker.plist

Disable autostart:

launchctl unload ~/Library/LaunchAgents/com.asc.master.plist
launchctl unload ~/Library/LaunchAgents/com.asc.worker.plist
